# 🚀 GFD Roadmap

> **A practical roadmap to master GATE, Full Stack Development, and DSA — all in one place.**

**GFD Roadmap** is an interactive learning platform designed to help students and aspiring developers organize their preparation journey across **GATE, Full Stack Development, and Data Structures & Algorithms (DSA)**.

🌐 **Live Demo:** https://gfdroadmap.vercel.app

---

## ✨ Features

* 📚 **GATE Roadmap** — Structured preparation path for GATE aspirants
* 💻 **Full Stack Roadmap** — Step-by-step journey from web fundamentals to full-stack development
* 🧠 **DSA Roadmap** — Topic-wise path for mastering Data Structures & Algorithms
* 🗺️ **Interactive Roadmaps** — Easily navigate through different learning stages
* 📖 **Learning Resources** — Curated resources to support preparation
* 🎯 **Progress-Oriented Learning** — Follow a structured path instead of learning randomly
* ⚡ **Modern UI** — Clean and responsive interface for a better learning experience

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/amankumar849/gfd_roadmap.git
```

### 2. Navigate to the project

```bash
cd gfd_roadmap
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:3000
```

---

## 🔑 Environment Variables

If required, create a `.env` file using the provided example:

```bash
cp .env.example .env
```

Add the required API keys/configuration inside the `.env` file.

> **Never commit your `.env` file or API keys to GitHub.**
